🚀 Sistema de Monitoramento com Orquestração de Agentes de IA
Este projeto representa o estado da arte na convergência entre Engenharia de Computação, Desenvolvimento Python e Automação Inteligente (RPA). Desenvolvido por Maria Evely da Silva, estudante do 9º período de Engenharia na UNIVESP, o sistema utiliza uma estrutura inovadora de multi-agentes de IA para gerenciar o ciclo de vida do desenvolvimento de software.

👩‍💻 Sobre a Autora
Bacharel em Direito, Historiadora e futura Engenheira de Computação. Este projeto é um marco no meu portfólio, demonstrando a aplicação prática de:

Python Avançado: Focado em predição de falhas e análise de dados.

RPA & Automação: Integração de fluxos de trabalho inteligentes.

Engenharia de Software: Gestão de agentes especializados para entrega de código robusto.

🤖 O Time de Agentes de IA
Para garantir a máxima qualidade e escalabilidade, o desenvolvimento foi orquestrado por 6 agentes especializados, cada um operando sob diretrizes técnicas rígidas:

📋 Product Owner (@PO): Define requisitos, cria User Stories e garante que o projeto resolva problemas reais de automação.

🏛️ Arquiteto de Software (@Arquiteto): Estrutura a árvore de diretórios e define os padrões de projeto para garantir a escalabilidade.

🐍 Backend Expert (@Backend): Desenvolve a lógica em Python focada em modularidade (PEP 8) e geração de logs para predição de falhas.

🎨 Frontend UI/UX (@Frontend): Cria interfaces responsivas e modernas utilizando o framework Bootstrap.

🧪 Engenheiro de QA (@QA): Focado na "previsão de falhas", realiza testes unitários rigorosos para tentar 'quebrar' o código e garantir sua robustez.

⚙️ DevOps & Automação (@DevOps): O mestre da eficiência, integra scripts de automação (RPA) e configura o ambiente de deploy.

🛠️ Tecnologias Utilizadas
Linguagem Principal: Python (Pandas, NumPy, Pytest).

Interface: HTML5, CSS3, Bootstrap.

Automação: Conceitos de RPA aplicados à infraestrutura.

Gestão de Contexto: Arquivos Markdown (.md) para persistência de memória dos agentes.

📈 Objetivo Técnico
O sistema foi projetado para monitorar métricas computacionais em tempo real, gerando logs estruturados que servem de base para algoritmos de detecção de anomalias e predição de falhas, unindo a teoria acadêmica da Engenharia de Computação com a prática do mercado de tecnologia.
